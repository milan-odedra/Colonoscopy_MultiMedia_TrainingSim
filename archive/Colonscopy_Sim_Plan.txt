Debug/Testing Mode
1. Debug Mode Toggle vs Startup Parameter
I'd suggest both options for maximum flexibility:
Option A: Command line parameter (recommended for final version)
python
if __name__ == "__main__":
    import sys
    debug_mode = "--debug" in sys.argv or "-d" in sys.argv
    PerceptionTestV2(debug_mode=debug_mode).run()
Option B: Runtime toggle key (good for development) Add a key like D to toggle debug mode on/off during the test.
Option C: Config file/environment variable for deployment.
I'd recommend starting with Option A - it's clean and prevents accidental toggling during a real test.
